Java OOP Machine Problems

This repository contains Java programs for three object-oriented programming machine problems. Each program uses classes, objects, arrays, loops, conditions, and user input.

Files

BATransacManager.java

This program is for the Bank Account Transaction Manager. It creates bank accounts, processes deposits and withdrawals, and prevents overdrafts.

CorManager.java

This program is for the Course Enrollment Manager. It stores student records, enrolls students in a course, and prevents duplicate enrollments or enrollment beyond the course capacity.

PGManSystem.java

This program is for the Parking Garage Management System. It parks compatible vehicles in available slots, calculates parking fees when vehicles exit, and tracks occupancy.
